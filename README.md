# 闫哲祯｜个人网站

个人网站源码，展示研究、工程项目与个人作品。使用 React、TypeScript、Vinext / Vite、Motion 与 Cloudflare 相关工具。

[访问网站](https://xiaoyan-personal-hub.s1encisi.chatgpt.site)

## 本地运行

使用 Node.js 22.13 或以上版本：

```bash
npm ci
npm run dev
```

```bash
npm test
npm run lint
node node_modules/typescript/bin/tsc --noEmit
```

`app/` 保存页面和组件，`public/` 保存运行所需素材，`tests/` 保存回归检查。GitHub 源码同步与线上网站部署分别管理。

个人照片与文字用于个人展示；第三方组件的许可证保留在相应源码目录。
