# 网站内容缺口清单

更新日期：2026-08-24

本清单只记录尚未获得、尚未核实或尚未获得公开许可的内容。网站在这些资料齐备前，不补写学校、导师、项目结果、论文、奖项、工具熟练度、联系方式或量化成绩。

## P0：最能改变网站可信度的资料

### 1. 基础身份与教育

- 希望公开的姓名与英文名
- 学校、学院、专业、年级、导师、实验室或团队
- 入学时间、预计毕业时间、所在城市
- 一段第一人称教育经历：为什么选择当前专业与研究方向
- 建议材料：最新简历 PDF 或 Word，加一段 500—1000 字叙述

对应页面：`/about/profile`、`/journey`、`/education`、`/education/masters-stage`

### 2. 一项最成熟的真实研究项目

- 正式项目名称、起止时间、所属机构、团队与个人角色
- 研究对象、输入输出、目标、约束与成功标准
- 数据来源、样本量、时间范围、预处理与拆分方式
- 基线、模型、配置、重复实验、评价指标与数值结果
- 个人完成的代码、实验、分析、写作或协作工作
- 失败案例、限制、下一步以及可公开图表或链接
- 建议材料：项目总结、实验表、数据字典、图表、仓库或报告

对应页面：`/projects/*`、`/outputs/project-results`、`/experience/masters-research`

### 3. 论文或公开成果

- 正式题名、成果类型、作者顺序与本人署名
- 期刊或会议、投稿/接收/发表状态与年份
- DOI、出版社页面、预印本或可公开 PDF
- 摘要、主要发现、局限、个人贡献与项目关系
- 建议材料：DOI、BibTeX/RIS、论文首页或 PDF，加一段贡献说明

对应页面：`/publications`、`/publications/publication-record-01`、`/publications/publication-record-02`

### 4. 公开联系方式

- 常用邮箱
- GitHub、ORCID、Google Scholar 或其他学术主页
- 简历或公开项目主页
- 接受的合作方式与不希望公开的信息
- 建议材料：逐行链接清单与一段合作说明

对应页面：`/contact`

## P1：用于完整呈现能力与成长的资料

### 5. 科研、实习、课程设计与协作经历

- 机构、团队、角色、地点与准确起止时间
- 合作对象、团队规模和职责边界
- 具体任务、采用方法、关键判断、交付物与结果
- 困难、失败、复盘和能力变化
- 可公开报告、代码、论文、演示或项目链接

对应页面：`/experience`、`/journey`

### 6. 竞赛、奖项、奖学金与服务经历

- 准确名称、类别、等级或名次
- 主办或授予机构、日期与评选范围
- 个人或团队参评、团队角色和个人贡献
- 证书、官方名单、获奖作品或答辩材料
- 图片来源和公开许可

对应页面：`/honors`、`/honors/*`

### 7. 技术能力的真实使用证据

- 实际使用的语言、库、框架、专业软件与版本
- 每项技术在哪个项目、哪一步、解决了什么问题
- 可公开代码、Notebook、配置、图表、日志或报告
- 对应评价结果、性能成本、失败案例与个人负责部分
- 建议材料：仓库链接或目录压缩包，加一份“技术—项目—证据”对照表

对应页面：`/skills`、`/skills/*`

## P2：用于增加个人辨识度与长期阅读价值的资料

### 8. 个人介绍与研究选择

- 为什么选择铜电积与电解液净化
- 兴趣如何从过程问题延伸到建模、优化与可信智能
- 一到两个真实转折、困难或影响判断的经历
- 未来两到三年想解决的问题与可公开规划

对应页面：`/about`、`/about/profile`

### 9. 知识库案例与来源

- 每个主题一项真实研究或实验作为贯穿案例
- 数据拆分图、评价结果、失败样本或流程图
- 教材、论文、官方文档或规范来源
- 创建日期、更新日期、适用读者与适用边界

对应页面：`/notes/*`

### 10. 随想完整原稿

- 最终标题、完整正文、写作日期和主题标签
- 一到两个真实情境、当时笔记或允许公开的片段
- 需要匿名化的信息、希望保留原样的句子与公开范围

对应页面：`/thoughts/*`

### 11. 吃喝、旅行与其他文娱记录

- 真实体验的日期、地点、背景、同行人数与实际价格
- 推荐理由、不推荐条件、注意事项与复盘
- 原创图片、拍摄者、授权说明与官方链接
- 旅行还需要逐日路线、交通、耗时、预约、预算与步行强度

对应页面：`/life/local-flavors`、`/life/coffee-tea`、`/life/travel-walks`、`/life/culture-objects`

## 推荐补充顺序

1. 最新简历与公开联系方式
2. 一项最成熟项目的完整材料
3. 已投稿、接收或发表成果的 DOI/BibTeX/PDF
4. 奖项证书或官方名单
5. 技术—项目—证据对照表
6. 个人介绍、随想和生活记录原稿
