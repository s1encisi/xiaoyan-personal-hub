# 2026-09-11 全站视觉与动效改造

依据《个人主页线上视觉审阅与逐页改造计划》实施。首页、铜电积案例与 2025 总表三个静态样板经本人确认后，推广到全部页面类型。本人随后明确取消真实手机验收；移动尺寸、横屏、浏览器缩放与键盘检查仍保留。

## 实现

- **首页开场**：复用原有星体图像，以 Motion 实现星体推进、光线展开、姓名揭示和进入首页的衔接。借鉴 [南孚官网](https://www.nanfu.global/) 的主体推进与品牌揭示节奏，未复制其视频或品牌资产。实时开场约 3.2 秒，每个标签页会话自动播放一次，可跳过、按 Escape 关闭或重播。减少动态时不播放，脚本缺失时正文直接可读。
- **动效分工**：Motion 负责开场与摄影预览；React Bits 的 BlurText 用于短装饰文案，StarBorder 仅强调首页研究入口。学术正文不逐段入场，目录仍是原生锚点。页标题线条使用轻量 CSS，避免为正文页单独加载完整动效库。
- **导航**：修复移动菜单被 backdrop-filter 限制在页头高度的问题；保留完整链接、焦点约束、Escape 和原滚动位置。桌面菜单收紧留白，关闭按钮水平显示。动画二级导航在窄屏完整显示，年份导航明确当前项。
- **专业内容**：项目与技能详情采用目录、事实、方法、结果、关联阅读的结构；能力索引连接真实项目。论文题录缩短面包屑，完整题名、作者、期刊、年份和状态在同一标题区；笔记与随想采用连续阅读列。
- **生活与动画**：保留摄影、海报和原文。照片故事提供回到目录的入口，正文图片按原比例显示；影评标题先于海报出现，横图采用自然比例；年度总表以作品名为主，年度推荐的编排说明放在作品之后。
- **共用规则**：收敛标题尺度、段落间距、辅助标签颜色、状态标签断行与手机页脚列数。开场、CSS 与 Canvas 均遵循现有动效偏好。

## 数据与素材

改造前后核对了六个主要内容文件和 125 个公开资源的 SHA-256，内容与资源本体保持一致。保留 105 个正式地址、五个旧地址跳转、十个现场锚点、2,276 条总表记录、54 条年度推荐，以及全部研究、履历和影评记录。论文状态与实验数值未因排版改造而改写。原始私人资料继续留在忽略目录。

## 验证方法

使用独立 Chromium 会话检查双端页面、真实交互及浏览器 200% 缩放。默认 Playwright 会强制前台焦点；后台检查另用新建的 Chromium 默认上下文，通过 `connectOverCDP({ noDefaults: true })` 保留原生可见性。实际记录 Canvas 绘制次数，验证后台停止、返回恢复，以及暂停、刷新保持、离屏和系统减少动态。

纯色背景文字按实际计算样式核对；复杂主视觉通过隐藏文字但保留布局后的截图，在真实文字行范围内取背景像素测量。没有把空白区域或没有文字覆盖的图像高光当作文字背景。

性能使用同一设备、40 ms 延迟、4 Mbps 下载、1 Mbps 上传、4 倍 CPU 限速、禁用缓存，在三个样板的桌面和手机尺寸各运行三次。具体结果由本轮验证记录给出；不将动画增加后的开销写成性能提升，也不将构建通过当作视觉验收。

## 最终检查记录

- `npm test`：28 项通过，包含构建、105 地址、旧路由、元数据、图片与内容边界。
- `npm run lint` 与根目录 `tsc --noEmit`：通过；补齐了原先缺失的 Workers 运行时类型。
- 105 页面 × 桌面/手机尺寸：210 组状态；另测 75 组窄屏、平板、1020/1021 断点与横屏状态。
- 浏览器原生 200% 缩放检查覆盖首页、案例、总表与长英文题录。
- 菜单全部 16 个子入口可到达；Escape、焦点和滚动恢复、年份前进/返回、目录、原图新标签页均完成交互验证。
- 开场在桌面、手机尺寸、横屏下检查跳过、自然结束、重播、刷新不重复和播放中开启减少动态；无脚本时首页可读。
- 三个主题的 Canvas 实际绘制次数在暂停、离屏、OS reduce 与真实后台状态下停止，返回可见状态恢复。
- 728 组纯色文字/背景样本未发现低于目标的组合；16 个图片文字区域按实际文字行取样，大文字最低 3.364:1，小文字最低 5.906:1。该抽样不代替完整屏幕阅读器或全部浏览器认证。
