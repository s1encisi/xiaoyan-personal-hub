# 个人研究与生活作品集：项目说明

更新日期：2026-09-18。本文描述仓库实际实现，便于简历引用、现场演示与代码审阅。本轮知识库、日常图文、AI 定位与动效更新位于开发分支，尚未替换线上版本。

## 项目简介

这是一个用于求职与博士申请的个人作品集网站。它把原本分散的研究材料、论文、校园实践、个人照片和动画记录，整理为首页、栏目索引与独立详情，让访客能够从一句概述进入具体工作、个人贡献和结果依据。

使用者主要是面试官、潜在博士导师和研究同行。首屏承担定位，项目详情承担证据，生活与长期兴趣补充沟通、表达及持续投入的一面。

## 从实际问题到实现

| 实际问题 | 实现方式 | 可以现场检查的证据 |
| --- | --- | --- |
| 一页简历无法承载项目细节 | 首页分流、栏目索引、独立详情与章节目录 | 从首页打开铜电积案例，定位“结果与交付” |
| 论文状态与个人分工容易在复制中失真 | 类型化记录、明确状态、结果紧邻比较条件 | 对照在审论文与已发表论文页面 |
| 学术、动画和生活内容不适合使用同一种布局 | 共用设计系统，按内容采用不同主题及阅读结构 | 首页、动画首页、摄影长文对照 |
| 动效可能干扰阅读或消耗资源 | 可跳过开场、暂停、减少动态、可见性控制 | Escape、系统 reduce、暂停后刷新 |
| 资料分散，网站需要独立运行 | 网站所用事实与图片独立整理，源码不依赖完整原稿 | 新克隆安装并构建，核对页面资源 |
| 页面多，手工维护容易产生断链 | 数据驱动模板、构建产物回归 | `npm test` 的运行结果 |

## 系统结构

- **内容层**：`app/_data/career.ts` 管理项目、论文、教育、经历、荣誉和技能；`personal-writing.ts` 管理方法笔记、随想和生活分类；摄影记录及图像属性分开维护。
- **延伸阅读**：`notion-library.ts` 保存主题导引及 Notion 原页面链接；`journal-data.json` 保存日常记录和图片尺寸。Notion 正文与网站摘要分别维护，当前没有后台自动同步服务。
- **页面层**：固定栏目路由与 `[slug]`、`[year]` 详情模板复用结构，正文保持记录自己的内容。Canonical、社交分享和 sitemap 对应实际地址。
- **交互层**：页头负责菜单、键盘、焦点和滚动恢复；页内目录使用原生锚点；Motion、CSS 和 Canvas 共享动效偏好。
- **资源层**：图片随项目发布，标注尺寸、替代文字与响应式变体。个人照片保留真实内容，第三方视觉素材保留来源；当前首页使用星云主题图，机器学习、强化学习和智能体案例配有新的概念意象。
- **交付层**：锁文件约束依赖版本；构建、Lint、类型检查和回归测试验证交付。GitHub 维护源码，Sites 承担线上运行。

`db/`、`drizzle/` 与部分 `worker/` 辅助文件来自保留的部署模板，当前网站未启用数据库。不能据此声称已实现在线内容后台或业务数据服务。

## 工程亮点

**把内容可信度变成结构。** 项目记录有问题、工作路径、评价与条件；论文区分已发表、修回和在审；同一研究的方法专题明确所属关系。内容建模承担了防止误述的作用。

**在共享设计系统内保留内容差异。** 天文首页、动画观测站和生活摄影分别承载个人定位、长期兴趣和真实经历。标题密度、阅读列、图片比例和导航共同决定布局，避免将全部内容压进一种卡片模板。

**动效具有退出与资源管理机制。** 开场按会话播放，允许 Escape 与手动跳过；Canvas 限制帧率及像素比，并响应页面与画布可见性。系统减少动态时，内容仍可直接阅读。

**公开范围可独立复现。** 新克隆只包含可公开内容即可构建，不依赖原始 Excel、私人记录或访问凭据。历史检查覆盖曾提交后删除的文件，使保护范围超过 `.gitignore`。

这些是针对个人内容网站的工程整合与产品取舍。没有提出新的前端算法，也不将第三方库本身写成原创成果。

## 本人贡献与工具协作

本人提供和核对内容，明确求职与申博双重用途，决定页面风格、动效方向、公开范围与验收要求。Codex 辅助完成资料整理、代码实现、浏览器验证和交付文档。网站展示的研究项目来自本人实际经历，网站建设与研究算法本身分别说明。

面试中适合重点讲自己能解释和演示的决策：为什么这样分栏、哪些材料没有公开、如何保持论文状态一致、动效如何退出、一次更新如何验证。不要将辅助生成的全部代码描述为逐行独立手写。

## 两分钟演示路径

1. 首页：说明研究定位；展示开场跳过和研究／生活入口。
2. 铜电积案例：展示问题、个人工作、数值结果以及对应条件。
3. 论文页：展示已发表、修回中、在审的区别。
4. 动画 2025 总表：展示大量内容仍然有完整年份入口与稳定链接。
5. 生活图文：展示真实摄影、自然比例、页内目录与原图入口。
6. 返回仓库：解释数据文件、一个详情模板、自动测试和上传检查。

GitHub README 提供个人介绍、精选照片和网站入口，完整内容保留在现有网站。当前开发版本新增日常入口及三个年度阅读页，知识库按主题跳转 Notion 全文；不另建网站。
