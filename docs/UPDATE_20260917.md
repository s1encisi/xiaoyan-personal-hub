## 视觉与交互

首页改为真实地平线、晨光与缓慢镜头移动。开场持续约 3.6 秒，宽幅画面逐步展开后进入姓名和主页；保留跳过、Escape、重播、焦点恢复和系统减少动态支持。背景在暂停、切到后台、离开视口或开场播放时停止移动。生活栏目采用与生活内容匹配的环境动效。

参考了 [Vast](https://www.vastspace.com/) 的大幅影像、黑色留白与节奏，以及 [Axiom Space](https://axiomspace.com/) 的视觉层级；浏览器实际检查了参考页面及 Vast 视频推进。实现采用轻量本地图片与 CSS 镜头运动，没有复制参考站的视频或代码，也未实现实时三维地球。

地球大气层照片来自 NASA 的 [ISS068-E-044995](https://www.nasa.gov/image-article/an-orbital-sunrise-begins-illuminating-earths-atmosphere/)，按 [NASA 媒体使用指引](https://www.nasa.gov/nasa-brand-center/images-and-media/)保留来源。三个 WebP 尺寸约为 8、23、40 KB；正文照片采用响应式尺寸与懒加载。
